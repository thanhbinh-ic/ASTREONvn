# Spanish Localization Voice Guide

## Global Direction

- Target Spanish: neutral international Spanish with a slight Latin American bias.
- Player-facing UI uses `tú`: `Selecciona`, `aceptas`, `¿Seguro que quieres...?`.
- Keep Ren'Py variables, tags and timing untouched: `[mc]`, `[mc!t]`, `{w}`, `{i}`, `{b}`, `{color=...}`.
- Preserve character names, brands, URLs and usernames unless the source is a role/title.
- Avoid literal machine patterns such as `hacer una conversación`, `en mis nervios`, `están terminados`, `puso un nervio`.
- Prefer natural dramatic prose over word-for-word English syntax.
- Repeated lore terms must stay consistent.

## Character Voices

### MC / `[mc]`

- Voice: dry, reactive, wounded, direct. Uses short sentences when tense.
- Spanish: informal `tú`; inner thoughts can be sharper and more fragmented.
- Avoid: overexplaining, ceremonial language, stiff literal phrasing.
- Example tone: `No. Eso no encaja. Algo aquí está mal.`

### Lora / `L`, `Lor`, `Lo`

- Voice: intimate, teasing, emotionally open, sometimes nervous.
- Spanish: warm, natural, soft rhythm; affection should feel lived-in, not syrupy.
- Avoid: clinical wording and overly formal romance.
- Example tone: `Solo... quédate conmigo un momento, ¿sí?`

### Olivia / `h`

- Voice: pragmatic, grounded, protective, with quiet fatigue.
- Spanish: concise and steady; jokes should be dry, not goofy.
- Avoid: melodrama unless the source clearly breaks her composure.
- Example tone: `Respira. Primero salimos de aquí; luego discutimos.`

### Kalestra / `k`

- Voice: dangerous, royal, controlled, contemptuous when threatened.
- Spanish: elegant but cutting; uses precise threats, not slang.
- Avoid: casual filler, weak insults, softened commands.
- Example tone: `No confundas mi paciencia con permiso.`

### Miriel / `Mi`

- Voice: kind, ancient, composed, maternal without sounding fragile.
- Spanish: calm and measured; uses gentle clarity.
- Avoid: childish sweetness or stiff academic phrasing.
- Example tone: `Lo sé. Pero incluso el dolor necesita un lugar donde descansar.`

### Flora / `Fl`

- Voice: brilliant, analytical, caustic, impatient.
- Spanish: precise technical language with sharp irony.
- Avoid: rambling machine syntax and generic scientist clichés.
- Example tone: `Eso no es una hipótesis, es una forma elegante de entrar en pánico.`

### Anya / `C`, `CC`

- Voice: vulnerable, sincere, quietly brave; uncertainty matters.
- Spanish: emotionally direct, with pauses where she hesitates.
- Avoid: making her sound too polished when she is afraid.
- Example tone: `No estoy segura... pero quiero intentarlo.`

### Shiya / `S`

- Voice: disciplined, focused, restrained, internally intense.
- Spanish: controlled and deliberate; emotion leaks through small cracks.
- Avoid: casual slang unless the source uses it.
- Example tone: `No necesito que sea fácil. Necesito que sea posible.`

### Ivy / `i`

- Voice: observant, sharp, slightly playful when safe.
- Spanish: quick, clever, with emotional intelligence.
- Avoid: turning wit into random sarcasm.
- Example tone: `Eso fue casi convincente. Casi.`

### Ember / `em`

- Voice: authority, command, controlled urgency.
- Spanish: formal command register; concise strategic language.
- Avoid: softening military stakes.
- Example tone: `Informe. Sin adornos. Necesito hechos.`

### Astoria / `am`

- Voice: mythic, sovereign, distant, symbolic.
- Spanish: elevated but readable; poetic restraint.
- Avoid: purple prose that obscures meaning.
- Example tone: `Toda corona exige un precio. La mía no fue distinta.`

### Ray / `rey`, Dr. Li Wei / `R`

- Voice: scientific, careful, haunted by implications.
- Spanish: precise, reflective, avoids emotional exaggeration.
- Avoid: translating technical statements into vague drama.
- Example tone: `La anomalía no contradice nuestras leyes. Expone sus límites.`

### Soldiers / `g`, `gg`, `ggg`, `ex`, `F`, `r`

- Voice: clipped, procedural, battlefield pressure.
- Spanish: terse military register.
- Avoid: long elegant sentences under combat conditions.
- Example tone: `Unidad Seis-Bravo, confirme posición. Repito: confirme posición.`

### System / `H`, Robot / `l`, `ss`

- Voice: neutral machine/system output.
- Spanish: clean, impersonal, minimal.
- Avoid: emotional verbs and informal phrasing.
- Example tone: `Acceso denegado. Autorización insuficiente.`

## Dialogue Rules

- Keep fragments as fragments when the source is fragmented.
- Translate profanity by intensity, not literally.
- `Damn` often becomes `maldita sea`, `joder`, `demonios`, or can be omitted depending on rhythm.
- Do not translate names hidden inside usernames or credits.
- If a line is a joke, preserve the function of the joke even if the wording changes.
- If a sentence sounds like English with Spanish words, rewrite it.
